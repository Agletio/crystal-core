# Decisions — standing art direction

Anything Astra settles that outlives one job. Claude reads these and follows
them without being asked again, the way `CLAUDE.md` is followed.

One file a subject, named for it: `PALETTE.md`, `PROPORTIONS.md`,
`LIGHT.md`, `WATER.md`. Say what is true and what it costs; a decision that
does not say what it rules out will be broken by accident.

A decision here binds Claude's *integration* choices — which picture is drawn
where, at what tint, in what order. It does not bind gameplay: if following it
would change what a player can do, that is a brief back to Claude, not a
decision.
