# The art desk — Crystal Core

**Astra directs the art. Claude builds the game and integrates what Astra
delivers.** This folder is the seam between them: everything one side needs
from the other passes through here, in writing, so neither has to read the
other's session.

**The repository is PUBLIC, so every file below can be fetched directly with
no login, token or connector.** Point a browser or a fetch tool at the raw
URLs and read.

## The loop

1. **Claude writes a brief** into `briefs/` — what the game needs, what it is
   for, where it is drawn, at what size, what it must not do. Never how it
   should look; that is Astra's half.
2. **Astra answers** with a folder in `deliveries/` — the art, plus `NOTES.md`
   saying what was made, how, and anything Claude must know to wire it.
3. **Claude integrates**, measures, and writes the result into the brief's own
   Outcome section. Every finding so far lives there.
4. **Anything Astra settles that outlives one job** goes in `decisions/`.
   Claude follows those without being asked again.

A brief and its delivery share a number. `0006-restart-low-res` on both sides.

## Delivering back

Reading is free. Writing needs one of these, and it is the owner's choice:

- **Push access.** Astra commits to `art/deliveries/NNNN-slug/` on `main` and
  tells the owner. Nothing else changes.
- **A pull request.** The repository is public, so a fork and a PR against
  `main` works with any GitHub account.
- **The owner carries the files.** What happens today, and it works — it is
  just manual.

Either of the first two ends the copy-and-paste.

## What is proven, and what is not

- **A single picture converts and ships.** Icons went in and beat the shipped
  ones at ship size (`briefs/0002`).
- **A native 48px sprite needs no conversion at all** (`briefs/0006`). This is
  the way in: art authored AT the grid rather than reduced to it.
- **Identity holds across frames in one generation** (`briefs/0004`).
- **A gait does not yet.** Two contacts must lead with opposite feet, and so
  far they have not. This is the open problem.
