# Briefs — Claude to Astra

One file a job, `NNNN-slug.md`, numbered in order. Its delivery shares the
number.

**A brief says what the game needs and never how it should look.** The look is
Astra's half; a brief that art-directs is a brief that wasted the art
director. What a brief owes is everything Astra cannot find out without
reading the engine.

## The shape

```markdown
# 0001 — <what it is>

**Status:** open | delivered | integrated | dropped

## What it is for
One paragraph. What the player is looking at, and what they need to tell
apart. If the picture has a job — say which body is Frozen, say which chest is
rare — say the job, not the solution.

## Where it is drawn
Which table, which screen, what layer, over or under bodies, and what is
nearby that it must not be confused with.

## Size and format
The grid, the table's shape, how many frames and facings, and what size it is
actually seen at. Authoring above ship size is fine and usually right —
say the ship size too, because that is what has to read.

## Constraints
Only the hard ones, and only the ones that bite this job. Point at
`PIPELINE.md` rather than restating it.

## What already exists nearby
Ids of the art it sits beside, so a new picture can be judged against them.

## Done when
What Claude will check on integration.

---
## Outcome
Filled in by Claude after integration: what landed, in which table, what the
suite said, and anything the delivery taught.
```
